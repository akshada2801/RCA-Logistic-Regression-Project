# RCA Project: Logistic Regression

**Title:** Implementation and Analysis of Logistic Regression for Binary Classification

## Aim
Train a Logistic Regression classifier using the Breast Cancer Wisconsin Diagnostic dataset and evaluate it with classification metrics.

## Dataset
Scikit-learn built-in dataset. Features include radius, texture, perimeter, area, smoothness and related measurements.
- Target 1 = Malignant
- Target 0 = Benign

## Libraries
Python, NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn.

## Project Workflow
1. Load dataset and inspect it
2. Check missing values and duplicates
3. Perform EDA and visualizations
4. Split into training and testing sets
5. Scale features and train Logistic Regression
6. Predict classes and probabilities
7. Evaluate with confusion matrix, accuracy, precision, recall, F1-score and ROC-AUC
8. Plot metric comparison and ROC curve
9. Export predictions and metrics to CSV

## Run
Open the `.ipynb` notebook in Google Colab and select **Runtime → Run all**.

> Educational project only. Not intended for medical diagnosis or clinical decisions.
